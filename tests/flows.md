# 화면 흐름 케이스

사이트 화면(`assets/app.js`·`assets/style.css`·`index.html`)을 바꾼 뒤 push 전에 휴대폰 크기(375×812)로 전부 돌린다.
돌린 쪽은 케이스 ID | 결과(통과·실패) | 증거(본 화면·값) 표를 남긴다.

- 준비: `python3 -m http.server` 로 띄우고, 진행 상태가 없는 상태(`localStorage.clear()`)에서 시작한다. 동기화 케이스(S·V05)는 토큰이 없으면 연결 전 화면까지만 본다.
- 화면을 더하거나 주소·버튼을 바꾸면 이 목록에도 케이스를 더한다.

## 홈·메뉴 (H)

| ID | 시작 화면 | 조작 | 기대 결과 |
|---|---|---|---|
| H01 | `#/` | 연다 | 주제 카드 목록 + 동기화 카드(연결 전: 「GitHub 동기화 연결 ›」, 연결됨: 저장소 이름 한 줄) |
| H02 | `#/` | 주제 카드를 누른다 | `#/t/<주제>` 목차, 부별 장 목록·진행 표시 |
| H03 | 아무 화면 | 머리줄 왼쪽 메뉴 버튼 | 서랍 메뉴 열림: 주제 아코디언 → 장 목록(장 단계 아이콘)·목차·진행·복습·테스트, 전체 주제, 동기화 설정 |
| H04 | 서랍 메뉴 | 장을 누른다 | 메뉴가 닫히고 그 장 화면, 메뉴에서 그 장이 현재 표시 |
| H05 | 아무 화면 | 머리줄 오른쪽 동기화 상태 버튼 | `#/settings` 로 이동 |
| H06 | 주제 화면 | 아래 탭 목차·복습·테스트·기록 | 각 화면으로 이동, 누른 탭이 활성, 복습 탭 숫자 = 오늘 재점검 + 새 문제 |

## 읽기 (R)

| ID | 시작 화면 | 조작 | 기대 결과 |
|---|---|---|---|
| R01 | 목차 | 「이어 읽기」 | 아직 안 읽은 첫 항목 화면 |
| R02 | 장 화면 | 항목 체크 상자를 켠다·끈다 | 체크 상태와 장 진행이 바로 바뀜 |
| R03 | 항목 화면(장 중간) | 「읽음 체크」 | 다음 항목 화면 |
| R04 | 항목 화면(장 마지막) | 「읽음 체크」 | 장 완료 화면 `#/t/<주제>/done/<장>` |
| R05 | 항목 화면(읽은 항목) | 「✓ 읽음 (누르면 취소)」 | 읽음이 풀리고 같은 화면에 남음 |
| R06 | 장 화면 | 「‹ 이전 장」·「다음 장 ›」 | 앞·뒤 장, 첫 장·마지막 장에는 해당 버튼 없음 |
| R07 | 장 완료 화면 | 「다음 장 …」 | 다음 장 첫 안 읽은 항목 |

## 테스트 (T)

| ID | 시작 화면 | 조작 | 기대 결과 |
|---|---|---|---|
| T01 | 장 화면(모두 읽음) | 테스트 버튼 → 문제 끝까지 | 선택지 문제는 보기 선택 → 확신 선택 → 자동 채점(보기 없이 확신을 누르면 「먼저 답을 고르세요.」), 서술 문제는 답 입력 → 확신 → 정답 본 뒤 직접 채점 · 진행 막대가 문제마다 늘어남 |
| T02 | 테스트 중 | 선택지 목록을 본다 | 보기 사이 1px 구분선(테마 `--f7-list-item-border-color`) |
| T03 | 테스트 중 | 한 문제를 틀린다 | 회차 끝에 그 문제가 1번 더 나오고 회차가 끝남(무한 반복 없음) |
| T04 | 장 화면에서 시작한 테스트 끝 | 「돌아가기」 | 장 화면, 장 단계 갱신 |
| T05 | 장 완료 화면 「장 테스트 (n문제)」 끝 | 「돌아가기」 | 장 완료 화면 |
| T06 | 복습 화면에서 시작한 테스트 끝 | 「돌아가기」 | 복습 화면, 남은 수 갱신 |

## 복습·기록 (V)

| ID | 시작 화면 | 조작 | 기대 결과 |
|---|---|---|---|
| V01 | `#/t/<주제>/review` | 연다 | 「재점검 시작 (n)」·「새 문제 테스트 (n)」, 둘 다 0 이고 안 읽은 장이 있으면 「읽을 장 보기」 |
| V02 | 복습 화면 | 「새 문제 테스트」 또는 「재점검 시작」 → 끝 | T01 과 같은 흐름, 끝난 뒤 수가 줄어듦 |
| V03 | `#/t/<주제>/log` | 연다 | 「GitHub 동기화」 블록(연결 전이면 「동기화 설정으로」)·「직접 옮기기」 블록(결과 요약·백업 내보내기·가져오기) — 회차 기록 목록은 없음 |
| V04 | 기록 화면 | 「결과 요약 보기·복사」 | 문제 ID 별 틀림·확신 오답 요약이 보임 |
| V05 | 기록 화면(연결됨) | 「결과 보내기」 | 성공 표시, 데이터 저장소 `results/<주제>/` 에 파일 |
| V06 | 기록 화면 | 「백업 내보내기」 | 진행 상태 파일 내려받기 |

## 동기화 설정 (S)

| ID | 시작 화면 | 조작 | 기대 결과 |
|---|---|---|---|
| S01 | `#/settings`(연결 전) | 연다 | 저장소·토큰 입력 칸과 안내 |
| S02 | `#/settings` | 「확인하고 저장」 | 연결됨 표시, 머리줄 동기화 버튼 상태 바뀜, 홈 동기화 카드가 한 줄로 |
| S03 | `#/settings`(연결됨) | 「모든 주제 지금 동기화」 | 오류 없이 끝남 |
| S04 | `#/settings`(연결됨) | 「이 기기 연결 끊기」 → 확인 | 이 기기 토큰만 지워지고 연결 전 화면 |
