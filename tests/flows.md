# 화면 흐름 케이스

사이트 화면(`assets/app.js`·`assets/style.css`·`index.html`)을 바꾼 뒤 push 전에 휴대폰 크기(375×812)로 전부 돌린다.
돌린 쪽은 케이스 ID | 결과(통과·실패) | 증거(본 화면·값) 표를 남긴다.

- 준비: `python3 -m http.server` 로 띄우고, 진행 상태가 없는 상태(`localStorage.clear()`)에서 시작한다. 동기화 케이스(S·V05)는 토큰이 없으면 연결 전 화면까지만 본다.
- 화면을 더하거나 주소·버튼을 바꾸면 이 목록에도 케이스를 더한다.

## 홈·내비 (H)

| ID | 시작 화면 | 조작 | 기대 결과 |
|---|---|---|---|
| H01 | `#/` | 연다 | 「오늘」 탭 활성, 「이어 읽기」 카드(읽을 항목이 있으면)·주제 목록·「기기 동기화」 한 줄(연결 전: 「연결 안 됨 · 이 브라우저에만 저장 중 · GitHub 연결」, 연결됨: 「동기화 연결됨 · 저장소 이름 · 설정」) |
| H02 | `#/topics` | 연다 | 주제 카드 4개(topics.json 순서), 이름 말줄임 없음, 카드 안 진행 막대·「진행 n%」, 이어 읽기 버튼은 「다음: <장 ID>」(「n장」 표기 없음)이고 채움은 가장 최근에 읽은 주제 하나, 나머지는 옅은 바탕 |
| H03 | 아무 화면(테스트 회차 밖) | 아래 탭 오늘·주제·복습·설정 | 각각 `#/today`·`#/topics`·`#/review`·`#/settings`, 누른 탭만 옅은 파란 바탕 + 굵은 글자. 서랍 메뉴·머리줄 메뉴 버튼은 없음 |
| H04 | 아무 화면 | 「복습」 탭 배지 | 모든 주제 오늘 재점검 수 합(0 이면 배지 없음), 빨강 바탕 흰 글자 — 테스트 회차를 끝내면 다시 셈 |
| H05 | `#/t/<주제>/c/<장>`·항목·장 완료 | 위 막대 | 왼쪽 「‹」(장 → 목차, 항목·장 완료 → 장), 가운데 한 줄 「<주제 이름> ▾ › <장 ID>」, 주제 이름은 강조색이고 375 폭에서 길면 주제 이름 쪽만 말줄임 |
| H06 | 경로가 있는 화면 | 주제 이름(▾) | 아래에서 주제 바꾸기 시트: 주제 4개(「주제」 탭과 같은 순서), 둘째 줄 「진행 n% · 다음 <장 ID>」, 지금 주제에 ✓ — 다른 주제를 누르면 그 주제 목차, 「닫기」·가림막·Esc 로 닫힘 |
| H07 | `#/t/<주제>` | 연다 | 「주제」 탭 활성, 부별 접기(지금 장이 든 부만 펼침), 장 행마다 상태 기호 ○◔◑◕● 를 세로 선으로 이음, 지금 장 강조 |
| H08 | `#/t/<주제>`(읽을 항목이 남음) | 떠 있는 「지금 장으로」 | 지금 장이 든 부가 펼쳐지고 그 장 행이 화면 가운데로 옴 |
| H09 | `#/`·`#/topics`·목차·항목·`#/settings` | 375·768·1024 폭, 밝은·어두운 | 가로 스크롤 없음, 768 이상은 본문·시트·항목 아래 바 560px 가운데 |

## 읽기 (R)

| ID | 시작 화면 | 조작 | 기대 결과 |
|---|---|---|---|
| R01 | 목차 | 「이어 읽기」 | 아직 안 읽은 첫 항목 화면 |
| R02 | 장 화면 | 항목 체크 상자를 켠다·끈다 | 체크 상태와 장 진행이 바로 바뀜 |
| R03 | 항목 화면(장 중간) | 아래 바 「읽음 ✓」 | 다음 항목 화면 |
| R04 | 항목 화면(장 마지막) | 아래 바 「읽음 ✓」 | 장 완료 화면 `#/t/<주제>/done/<장>` |
| R05 | 항목 화면(읽은 항목) | 아래 바 「✓ 읽음 / 누르면 취소」(초록 테두리) | 읽음이 풀리고 같은 화면에 남음 |
| R08 | 항목 화면 | 아래 바 「‹ 이전」·「다음 ›」(장 마지막 항목은 「장 마치기 ›」) | 읽음은 그대로 두고 앞·뒤 항목(장 첫 항목의 이전 = 앞 장 마지막 항목, 주제 첫 항목은 「‹ 이전」 흐림), 장 마지막은 장 완료 화면. 채움 버튼은 「다음」 하나, 바는 아래 탭 바로 위에 붙고 본문 끝이 가리지 않음 |
| R09 | 항목 화면 | 스크롤 | 위 「n / m」(장 안 순번 / 장 안 항목 수)·장 읽음 막대·「항목 목록 ▾」 줄이 머리줄 바로 아래 남음 |
| R10 | 항목 화면 | 「n / m」 줄(「항목 목록 ▾」 포함 줄 전체) | 아래에서 장 안 항목 목록 시트(아래 탭까지 덮음): 머리 「<장 ID> <장 이름>」·「m개 중 k개 읽음」·「닫기」, 행마다 읽음 ✓·안 읽음 ○, 지금 항목은 옅은 파란 바탕 — 다른 항목을 누르면 그 항목으로 가고 시트 닫힘, 「닫기」·가림막·Esc 로 닫힘 |
| R06 | 장 화면 | 「‹ 이전 장」·「다음 장 ›」 | 앞·뒤 장, 첫 장·마지막 장에는 해당 버튼 없음 |
| R07 | 장 완료 화면 | 「다음 장 읽기: <장 제목> ›」(테스트할 문제가 있으면 「나중에 하기 — 다음 장 읽기」) | 다음 장 첫 안 읽은 항목 |

## 테스트 (T)

| ID | 시작 화면 | 조작 | 기대 결과 |
|---|---|---|---|
| T00 | 장 화면(모두 읽음)·장 완료·복습 | 테스트 시작 → 위 막대 「그만두기」 | 회차 중 아래 탭 숨김·위 막대엔 「그만두기」만, 누르면 시작한 화면으로 돌아가고 아래 탭이 다시 보임(푼 문제까지 저장) |
| T01 | 장 화면(모두 읽음) | 테스트 버튼 → 문제 끝까지 | 선택지 문제는 보기 선택 → 확신 선택 → 「제출」(둘 다 고르기 전엔 비활성, 제출 전엔 보기·확신을 바꿀 수 있음) → 자동 채점(보기 없이 확신을 누르면 「먼저 답을 고르세요.」), 서술 문제는 답 입력 → 확신 → 「제출」 → 정답 본 뒤 직접 채점 · 진행 막대가 문제마다 늘어남 |
| T02 | 테스트 중 | 선택지 목록을 본다 | 보기 사이 1px 구분선(테마 `--f7-list-item-border-color`) |
| T03 | 테스트 중 | 한 문제를 틀린다 | 회차 끝에 그 문제가 1번 더 나오고 회차가 끝남(무한 반복 없음) |
| T04 | 장 화면에서 시작한 테스트 끝(점수 카드 「n문제 중 m개 통과」·막대·다음 재점검, 틀린 문제는 내 답·정답 줄) | 「돌아가기」 | 장 화면, 장 단계 갱신 |
| T05 | 장 완료 화면 「테스트 시작 (n문제)」 끝(점수 카드 「n문제 중 m개 통과」·막대·다음 재점검, 틀린 문제는 내 답·정답 줄) | 「돌아가기」 | 장 완료 화면 |
| T06 | 복습 화면에서 시작한 테스트 끝(점수 카드 「n문제 중 m개 통과」·막대·다음 재점검, 틀린 문제는 내 답·정답 줄) | 「돌아가기」 | 복습 화면, 남은 수 갱신 |

## 복습·설정 (V)

| ID | 시작 화면 | 조작 | 기대 결과 |
|---|---|---|---|
| V00 | `#/review` | 연다 | 「복습」 탭 활성, 주제마다 「재점검 n · 새 문제 m」 줄, 누르면 `#/t/<주제>/review`(「복습」 탭 활성, 경로 「<주제> ▾ › 복습」, ‹ → `#/review`) |
| V01 | `#/t/<주제>/review` | 연다 | 할 일이 있으면 채움 버튼 하나(재점검 있으면 「재점검 시작 (n)」, 없으면 「새 문제 테스트 (n)」)·나머지는 옅은 버튼, 숫자 줄 셋(오늘 재점검·새 문제·아직 다 읽지 않은 장). 둘 다 0 이면 체크 원·「오늘 볼 문제 없어요」·다음 재점검 날짜·「목차에서 이어 읽기」 |
| V02 | 복습 화면 | 「새 문제 테스트」 또는 「재점검 시작」 → 끝 | T01 과 같은 흐름, 끝난 뒤 수가 줄어듦 |
| V03 | `#/settings`·`#/t/<주제>/log` | 연다 | 「설정」 탭 활성, 동기화 블록 아래 「결과·백업」 블록: 주제 고르기(log 주소는 그 주제, `#/settings` 는 마지막으로 연 주제)·결과 보내기(연결됨일 때만)·결과 요약 보기·복사·백업 내보내기·가져오기 — 회차 기록 목록은 없음 |
| V04 | 설정 화면 | 「결과 요약 보기·복사」 | 문제 ID 별 틀림·확신 오답 요약이 보임 |
| V05 | 설정 화면(연결됨) | 「결과 보내기」 | 성공 표시, 데이터 저장소 `results/<주제>/` 에 파일 |
| V06 | 설정 화면 | 「백업 내보내기」 | 진행 상태 파일 내려받기 |
