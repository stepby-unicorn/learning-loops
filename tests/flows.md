# 화면 흐름 케이스

사이트 화면(`assets/app.js`·`assets/style.css`·`index.html`)을 바꾼 뒤 push 전에 휴대폰 크기(375×812)로 전부 돌린다.
돌린 쪽은 케이스 ID | 결과(통과·실패) | 증거(본 화면·값) 표를 남긴다.

- 준비: `python3 -m http.server` 로 띄우고, 진행 상태가 없는 상태(`localStorage.clear()`)에서 시작한다. 동기화 케이스(S·V05)는 토큰이 없으면 연결 전 화면까지만 본다.
- 일정 케이스(H11·H12)는 `topics/<주제>/index.json` 에 `schedule` 이 없으면 개발자 도구 콘솔에서 불러 둔 주제에 일정을 넣고 다시 그린다(새로고침하면 사라짐, 데이터 파일은 그대로):
  ```js
  const t = await getTopic((await getTopics())[1].id), k = (d) => dayKey(Date.now() + d * 864e5), c = t.chapters;
  t.schedule = [{ date: k(-2), chapters: [c[0].id, c[1].id] }, { date: k(0), chapters: [c[2].id, c[3].id] }, { date: k(1), chapters: [c[4].id] }];
  route(true);
  ```
- 화면을 더하거나 주소·버튼을 바꾸면 이 목록에도 케이스를 더한다.
